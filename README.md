# Cápsulas de seguridad digital

Programa de doce cápsulas en español con actividades prácticas y cuatro videos breves.

## Publicación

Este repositorio publica la web con GitHub Pages desde la raíz de la rama `main`.

## Abrir localmente

Abre `index.html` en un navegador y conserva las carpetas `assets` y `capsulas` junto al archivo.

## Funcionalidades

- Actividades con controles de teclado, ejemplos ficticios y reinicio.
- Videos con reproducción, pausa, subtítulos y transcripción.
- Diseño adaptable y preferencia de movimiento reducido.
- Progreso y preferencias guardados en el navegador, sin sincronización entre dispositivos.
- Resumen personal del recorrido; no constituye una acreditación oficial.

El material orienta el aprendizaje. Las actuaciones del trabajo deben seguir los procedimientos y las autorizaciones internos.
